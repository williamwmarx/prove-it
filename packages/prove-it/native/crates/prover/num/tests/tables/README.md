# Number tables

`int.txt` and `rational.txt` were recorded from the TypeScript SMT solver's integers and rationals
(`src/prover/smt/solver/rational.ts`) at commit f5b7bef, before it was deleted, by the now-deleted
`scripts/smt-foundation-tables.ts`.

They are frozen expected data. Nothing rewrites them now: a change to a line is a change to the
arithmetic's behaviour.
